Vulnerable & Outdated Components

Remote Code Execution via template options prototype pollution.

Core Vulnerability Concept

Applications frequently import external components and libraries. When these components are outdated or contain logical security defects (like EJS v3.1.6 template engine processing), attackers can inject properties that pollute system configurations or internal engine compile options (like `escapeFunction` or `outputFunctionName`), triggering arbitrary remote code execution.

Vulnerability Vectors

EJS v3.1.6 checks compile configurations from the render options parameter directly. If dynamic requests copy or merge user query parameters straight into rendering scopes, internal execution properties can be overridden.

Vulnerable Option Merging
// Direct query parameters exposure
res.render('index', {
  ...req.query
});
Secure Shallow Mapping
// Safe copy restricting parameters
res.render('index', {
  operator: req.query.operator
});
