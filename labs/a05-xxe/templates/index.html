XML External Entity (XXE) Injection

Exploiting weak parser configurations to disclose local resources and route internal packets.

Core Vulnerability Concept

XXE injection occurs when an XML parser parses untrusted user-supplied XML input that contains external entities definitions in the DOCTYPE declaration, and resolve_entities is enabled. This allows attackers to access local files, perform internal SSRF network scans, or cause Denial of Service (DoS).

Vulnerability Drivers

Naively configured libraries (such as lxml, libxml2, or xerces) often default to resolving external entities. Disabling entity resolution entirely or filtering external DTDs is the recommended approach to completely secure XML integration endpoints.

Vulnerable Parser Configuration
# lxml configured with resolve_entities
parser = etree.XMLParser(resolve_entities=True)
root = etree.fromstring(xml, parser=parser)
Secure Parser Configuration
# Explicitly disable external entity parsing
parser = etree.XMLParser(resolve_entities=False)
root = etree.fromstring(xml, parser=parser)
