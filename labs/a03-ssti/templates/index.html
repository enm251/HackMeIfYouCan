Server-Side Template Injection (SSTI)

Abusing template engine parsing logic to trigger remote code execution.

Core Vulnerability Concept

SSTI occurs when user-supplied input is dynamically concatenated into a template string and parsed by template engines (such as Jinja2, Twig, or EJS) instead of being passed as context values. This enables attackers to traverse Python/Node runtime objects, class hierarchies, and execution context, executing arbitrary OS shell processes.

Execution Requirements

Standard Jinja2 exploits invoke global attributes or object MRO resolution paths like self.__class__.__mro__ or lipsum.__globals__ to navigate context namespaces and acquire execution libraries (e.g. the os module).

Vulnerable Dynamic Parsing
# Unescaped string compilation
rendered = render_template_string(user_input)
Secure Parameterized Context
# Passing safe context variables
rendered = render_template("page.html", val=user_input)
